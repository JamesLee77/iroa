# MODUA

MODUA is an independent AI life-assistance and mutual-support project for older adults, disabled people, and the people who help them.

## Document authority

1. `docs/specs/modua-inclusive-agent-economy-design.md` is the approved design.
2. `docs/whitepaper/MODUA_WHITEPAPER_KO.md` is the editorial source of truth.
3. DOCX and PDF files are generated review artifacts.
4. HEFI documents are references only and never establish MODUA implementation, partnership, token, or medical claims.

## Build

Run `python scripts/validate_whitepaper.py` before `python scripts/build_whitepaper.py`.
