# Homepage override

홈페이지는 Light Network Atlas의 진입점이다. 공통 브랜드·색상·타이포그래피 토큰은 `MASTER.md`와 `tokens.css`를 그대로 사용하며 이 문서에서 재정의하지 않는다.

- 목적: IROA를 검증 가능한 실행 네트워크로 한 문장에 설명하고, 프로토콜·보안·경제·로드맵으로 탐색을 연다.
- 밀도: 한 화면에 하나의 핵심 판단을 두고 넓은 여백과 짧은 설명을 사용한다.
- 제목: `18ch` 안팎으로 제한해 네트워크 명제를 빠르게 읽게 한다.
- 흐름: 개요에서 근거로, 근거에서 상세 백서로 점진적으로 깊어진다.
- 행동: 주요 CTA는 Coral 면/Navy 글자 조합을 유지하고, 보조 행동은 surface와 border로 구분한다.
- 시각화: 노드와 연결선은 실제 개념 관계를 표현해야 하며 장식용 네트워크 노이즈를 만들지 않는다.
- 접근성: 모션 없는 상태에서도 관계와 탐색 순서가 완전해야 하며 상태 의미는 레이블과 형상을 동반한다.

CSS 범위는 `.page--homepage` 아래의 제목 measure와 구획 간격에 한정한다.
