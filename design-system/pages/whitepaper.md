# Whitepaper override

웹 백서는 인쇄 문서의 축약본이 아니라 탐색 가능한 근거 경험이다. 공통 브랜드 토큰은 재정의하지 않고 읽기 폭, 목차 탐색, 정보 밀도만 조정한다.

- 목적: 프로토콜, 보안 모델, 토큰 경제, 거버넌스, 로드맵의 주장과 근거를 연결한다.
- 읽기 폭: 본문은 60–75자 범위, 기본 `68ch`를 유지한다.
- 구조: 문서의 제목 계층을 건너뛰지 않고 섹션 앵커와 목차 레이블을 일치시킨다.
- 근거: 계획, 실증, 배포, 실제 운영을 별도 상태로 표시하고 출처와 갱신 시점을 붙인다.
- 데이터: 영문·숫자·표 값은 Inter와 tabular numerals를 사용하며, 표는 좁은 화면에서 의미 있는 헤더 관계를 유지한다.
- 강조: Teal은 검증 형상이나 큰 그래픽에 제한하고 Ivory 위 일반 본문색으로 쓰지 않는다.
- 접근성: 키보드 목차, 44px 탐색 타깃, 3px 포커스, 모션 감소, 확대 시 재배치를 보장한다.

CSS 범위는 `.page--whitepaper` 아래의 article measure, 구획 간격, 앵커 스크롤 여백에 한정한다.
