# IROA Web3 Design System

이 문서는 IROA.AI 웹 경험의 공통 시각·접근성 계약이다. 기준 방향은 승인된 Track A 아이덴티티와 **Light Network Atlas**다. 밝고 정밀한 정보 면 위에서 검증 가능한 연결, 실행 단계, 근거를 구조적으로 보여 준다.

## 1. 브랜드 원칙

- 공식 심볼, 워드마크, 락업은 `docs/brand/`의 승인 자산만 사용한다.
- 열린 고리와 행동점은 검증 가능한 연결을 뜻한다. 장식용 3D, 금속, 그림자, 임의 그라데이션으로 변형하지 않는다.
- 프로토콜, 보안, 경제, 로드맵의 관계를 네트워크 아틀라스처럼 명료한 선·노드·레이어로 설명한다.
- 사진이나 복잡한 그래픽 위에는 로고를 바로 얹지 않고 단색 정보 면과 보호 공간을 확보한다.

## 2. 색상 계약

브랜드 원색과 모든 원시 색상 값은 `src/styles/tokens.css`에서만 선언한다. 제품 CSS는 의미 토큰을 사용한다.

| 의미 | 토큰 | 용도 |
| --- | --- | --- |
| 페이지 배경 | `--color-bg` | 긴 탐색을 위한 밝은 중립 배경 |
| 정보 면 | `--color-surface` | 카드, 표, 내비게이션 |
| 부드러운 정보 면 | `--color-surface-soft` | 구획과 문서 보조 면 |
| 기본 글자 | `--color-text` | 제목과 본문 |
| 보조 글자 | `--color-text-muted` | 메타데이터와 보조 설명 |
| 핵심 행동 | `--color-action` | 주요 CTA와 행동점 |
| 행동 위 글자 | `--color-on-action` | 항상 Navy 계열 글자 |
| 검증 상태 | `--color-verified` | 아이콘·형상과 함께 쓰는 검증 신호 |
| 경계 | `--color-border` | 카드·입력·표 구분선 |
| 포커스 | `--color-focus` | 키보드 포커스 링 |

Coral 행동 면에는 Navy 글자만 사용한다. White-on-Coral은 금지한다. Teal-on-Ivory와 Teal-on-White는 일반 크기 본문에 사용하지 않고 큰 글자 또는 비텍스트 그래픽으로 제한한다. 상태는 색상만으로 전달하지 않고 문구, 아이콘 형상 또는 패턴을 함께 제공한다.

## 3. 타이포그래피

- 한국어는 Noto Sans KR Medium(500)과 Bold(700)를 사용한다.
- 영문, 숫자, 코드, 표의 수치에는 Inter Variable을 우선한다.
- 기본 폰트 스택은 Inter를 먼저 두고, Inter에 없는 한글 글리프가 Noto Sans KR로 자연스럽게 대체되도록 한다.
- 모바일 본문은 16px 미만으로 줄이지 않는다. 본문 행간은 `1.65`를 기준으로 한다.
- 긴 글의 한 줄 길이는 60–75자로 제한하며 기본 article measure는 `68ch`다.
- 긴 전부 대문자 제목, 압축 자간, 얇은 본문 글꼴을 피한다.

## 4. 간격과 레이아웃

- 간격은 `--space-1`부터 `--space-12`까지의 4px 기반 단계만 사용한다.
- 콘텐츠 최대 폭은 `--container`, 좌우 안전 여백은 `--gutter`로 통제한다.
- 넓은 화면은 `.grid-12`의 12열 구조를 사용하고, 모바일은 같은 유틸리티가 4열로 축소된다.
- 페이지 구획의 수직 리듬은 페이지 오버라이드의 `--page-section-space`로 조정한다.
- 긴 문서와 설명은 `.article-measure` 또는 `.prose`를 사용한다.

## 5. 아이콘과 데이터 그래픽

- 아이콘은 단순한 선형 기하와 일관된 stroke를 사용한다. 의미가 있는 아이콘에는 텍스트 레이블을 제공한다.
- 아이콘 단독 버튼은 `.icon-button`을 사용하고 접근 가능한 이름을 반드시 제공한다.
- 데이터 시각화는 색상 외에 레이블, 선 모양, 마커 또는 패턴을 병행한다.
- 수치와 표는 `.tabular`로 Inter와 tabular numerals를 적용한다.

## 6. 컴포넌트와 행동

- 모든 대화형 컨트롤의 최소 터치 영역은 `--control-min`(44px)이다.
- 주요 CTA는 Coral 면과 Navy 글자를 사용한다. 보조 CTA는 밝은 면과 경계선으로 위계를 낮춘다.
- 검증 상태는 `.status`처럼 문구와 형상을 함께 제공한다.
- 카드의 경계와 음영은 정보 계층을 만드는 정도로만 사용한다.

## 7. 모션

- 짧은 피드백은 `--motion-fast`, 기본 전환은 `--motion-base`, 감속은 `--ease-out`을 사용한다.
- 모션은 상태 변화나 공간 관계를 설명할 때만 사용한다. 지속적인 장식 애니메이션과 과도한 패럴랙스를 피한다.
- `prefers-reduced-motion: reduce`에서는 애니메이션과 부드러운 스크롤을 사실상 제거한다.

## 8. 접근성

- 모든 키보드 포커스는 3px 가시 포커스 링으로 표시한다.
- 스킵 링크와 단일 `main` 랜드마크를 유지한다.
- 본문 대비는 WCAG 2.x 기준 4.5:1 이상, 큰 글자와 필수 비텍스트 UI는 3:1 이상을 목표로 한다.
- 제목 계층, 링크 목적, 상태 문구가 DOM과 시각 표현에서 일치해야 한다.
- 확대, 고대비, 키보드 전용, 모션 감소 환경을 실제 페이지에서 검증한다.

## 9. 금지 패턴

- White-on-Coral 텍스트 또는 식별 필수 UI
- Ivory 위 Teal 일반 본문
- 브랜드 원색 HEX의 토큰 파일 외 재선언
- 색상만으로 완료·오류·대기 상태 구분
- 44px 미만 터치 타깃, 포커스 링 제거, 16px 미만 모바일 본문
- 장문의 전체 대문자, 로고 워드마크의 일반 텍스트 재조판
- 사실·계획·실증·운영·제휴·규제 승인을 같은 상태로 표현하는 과장 문구

## 10. 페이지 오버라이드

공통 토큰은 페이지 문서에서 재정의하지 않는다. 홈페이지와 백서의 정보 밀도, 제목 measure, 구획 간격만 `design-system/pages/` 규칙으로 좁힌다.
