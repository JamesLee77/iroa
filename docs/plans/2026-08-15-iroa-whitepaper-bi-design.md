# IROA.AI BI 및 백서 재설계

## 1. 목적

MODUA 참고 원고를 바탕으로 새로운 독립 브랜드 `IROA.AI`를 확립하고, 노인과 장애인이 일상 과업을 실제로 끝낼 수 있도록 돕는 AI Agent·Node 생태계를 설명하는 한국어 백서를 제작한다.

이번 작업의 중심은 문서 생성 도구가 아니라 서비스의 가치, 사용자 경험, 기술 구조, 개인정보 보호, 참여자 보상 및 현실적인 구현 순서다. 별도의 백서 생성 시스템은 만들지 않는다.

## 2. 브랜드 정의

- 공식 표기: `IROA.AI`
- 기본 워드마크: `iroa`
- 한국어 호칭: `이로아`
- 기술적 의미: `Inclusive Real-world Orchestration Agent`
- 사용자 약속: `일상을 이롭게.`
- 핵심 문구: `곁에서 함께, 필요한 일을 끝까지.`
- 영문 보조 문구: `Real Life, Made Easier.`

`IROA`는 AI가 설명만 하는 서비스가 아니라 사용자의 의사를 확인하고 예약, 이동, 주문, 결제, 병원·복지 연계 같은 생활 과업을 안전하게 완료한다는 뜻을 담는다.

## 3. 시각 방향

### 3.1 성격

- 따뜻하지만 유아적이지 않다.
- 기술적이지만 암호화폐 프로젝트처럼 보이지 않는다.
- 의료기관과 공공기관이 신뢰할 수 있으면서도 개인 사용자에게 친근하다.
- 장애와 고령을 동정이나 무기력의 이미지로 표현하지 않는다.

### 3.2 로고 개념

- 소문자 `iroa` 워드마크를 기본으로 한다.
- `o`는 사용자, Agent, Node가 연결되는 열린 고리를 상징한다.
- 복잡한 뇌, 로봇 얼굴, 코인, 블록체인 육각형 문양은 사용하지 않는다.
- 작은 화면과 워치에서도 식별되는 단순한 심볼을 별도로 제공한다.

### 3.3 색상

- IROA Navy `#16263D`: 신뢰, 기술, 본문과 주요 배경
- IROA Coral `#F06D5E`: 따뜻한 행동, 핵심 강조와 호출
- IROA Ivory `#F7F3EA`: 편안한 문서 배경
- IROA Teal `#3D8B83`: 안전, 건강·지역사회 연계
- Ink `#19222E`: 본문
- White `#FFFFFF`: 역상 표기

모든 본문과 인터페이스 조합은 WCAG 대비 기준을 충족하도록 사용한다. 코랄은 큰 제목, 심볼 또는 장식에 사용하고 작은 흰색 본문을 직접 올리지 않는다.

### 3.4 서체

- 한국어: Noto Sans KR
- 영문 및 숫자: Inter
- 문서 본문은 장시간 읽기에 적합한 크기와 행간을 사용한다.
- 작은 글자와 얇은 글꼴을 피하고 표·주석도 읽을 수 있는 크기를 유지한다.

## 4. 사진 원칙

Pexels 사진은 제공된 API 키로 조회하되 키 자체는 저장·출력·커밋하지 않는다. 사진 원본, 사진가 이름, Pexels 원문 링크, 검색어, 사용 위치를 매니페스트에 기록한다.

선정 우선순위:

1. 노인과 장애인이 도움의 대상만이 아니라 스스로 선택하고 행동하는 장면
2. 워치·음성·키오스크를 자연스럽게 사용하는 일상
3. 가족, 자원봉사자, 상점주, 의료·복지 담당자와의 협력
4. 집에서의 반려 친구와 안부 교류
5. 안전한 컴퓨팅 Node와 로봇 확장을 암시하는 장면

제외 기준:

- 과도하게 연출된 슬픔, 무기력, 고립
- 환자복·병상 위주의 의료화된 이미지
- 얼굴이나 건강정보를 감시하는 듯한 장면
- 특정 제품 또는 플랫폼의 공식 제휴로 오해할 수 있는 로고 노출
- 접근성 현실과 맞지 않는 과장된 미래 기술 이미지

## 5. 백서 이야기 구조

백서는 기술 계층보다 사용자의 하루에서 시작한다.

1. **생활 실행 Agent**: 요청 이해, 선택지 설명, 사용자 확인, 예약·주문·이동·결제의 완료
2. **가까운 접점**: 모바일, 전화, 워치, AI 키오스크, 반려 친구
3. **안전한 실행 기반**: 장시간 과업과 고성능 Computer Use를 처리하는 격리 Node
4. **개인정보와 신원**: 최소수집, 일회성 권한, 자격증명 금고, 작업별 격리, 감사 가능한 증명
5. **사람과 지역사회**: 보호자, 자원봉사자, 상점주, 병원·복지기관의 역할
6. **Node 경제**: 검증된 작업과 제공 자원에 대한 보상, 상점주 키오스크 비용 완화
7. **반려 친구와 로봇**: 고립 위험 완화, 단계적 안부 확인, 물리적 도움으로의 신중한 확장

## 6. 제품 체계

- IROA Agent: 생활 과업을 계획하고 완료하는 핵심 Agent
- IROA Mobile: 사용 가능한 사람을 위한 선택적 개인 접점
- IROA Watch: 요청, 확인, 안전 신호를 주고받는 가장 가까운 인터페이스
- IROA Node: 장시간·고성능·Computer Use 과업을 격리 실행하는 관리형 인프라
- IROA Kiosk: 현장에서 주문·예약·결제를 대행하는 Agentic Node
- IROA Companion: 대화, 일상 루틴, 단계적 안부 확인을 제공하는 반려 친구
- IROA Robot: Companion과 Node를 물리적 도움으로 확장하는 단계적 연구 제품
- IROA Network: 사용자, 도움 제공자, 기관, Node 운영자를 연결하는 신뢰·보상 계층

## 7. 기술 및 안전 원칙

- API를 우선 사용하고 Computer Use는 통제된 보완 수단으로 제한한다.
- 예약 확정, 결제, 의료정보 전송, 개인정보 제출 같은 결과가 큰 행동은 사용자의 명시적 확인을 받는다.
- 모바일 운영체제의 권한 범위를 넘는 자동화는 관리형 Node에서 실행한다.
- Node는 과업별 격리 환경, 짧은 수명의 권한, 암호화된 비밀 저장소를 사용한다.
- 블록체인에는 개인정보·건강정보·대화 원문을 기록하지 않는다.
- 블록체인은 비개인 증명, 보상 상태, 정책 버전 같은 제한된 기록에만 검토한다.
- IROA는 의료 진단, 응급 구조 또는 고독사 방지를 보장하는 서비스로 표현하지 않는다.
- 스테이블코인을 발행하지 않는다. 초기 보상은 원화와 비양도성 포인트를 우선한다.

## 9. 품질 기준

- IROA 이전 브랜드명이 독립 브랜드 본문에 남지 않는다. HEFI와 MODUA는 참고·이력 문맥에서만 제한적으로 언급한다.
- 백서 표지와 각 장의 사진은 내용을 설명해야 하며 장식 목적으로 과도하게 사용하지 않는다.
- DOCX와 PDF는 모든 페이지를 렌더링하여 잘림, 겹침, 깨진 한글, 낮은 대비가 없는지 확인한다.
- 사진 대체 텍스트, 제목 구조, 표 머리글, 언어 메타데이터를 포함한 접근성 검사를 수행한다.
- 상표권, 의료·개인정보·전자금융·가상자산 관련 문구는 공개 전 전문가 검토가 필요함을 명확히 표시한다.
