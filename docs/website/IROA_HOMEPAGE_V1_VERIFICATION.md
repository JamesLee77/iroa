## 배포 전 외부 결정 사항

아래 항목은 홈페이지 소스 결함이 아니라 실제 공개 전 별도 확정이 필요한 운영 사항이다.

- 공식 문의 채널 또는 개인정보 수집이 가능한 백엔드 연결
- `iroa.ai` 배포 환경과 DNS 연결
- 올바른 GitHub 원격 저장소 연결 및 병합 방식 확정
- 영문 페이지 범위와 번역 검수
- 법률, 개인정보보호, 접근성, 상표에 대한 별도 전문 검토
- 실제 파트너·파일럿 확정 후 “목표 경험” 상태 문구 갱신

현재 소스는 공식 문의 채널이 정해지기 전까지 개인정보 입력 폼을 제공하지 않는다. 또한 이 기록은 로컬 소스와 브라우저 렌더링 검증이며, 배포 또는 실제 운영을 증명하지 않는다.
