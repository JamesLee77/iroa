# MODUA 반려 친구·로봇·보안 노드 백서 개정 계획

**목표:** 기존 개인 PC 중심 설명을 MODUA 제공 보안 노드 중심으로 바꾸고, 독거노인을 위한 반려 친구와 단계적 로봇 확장을 서비스·개인정보·보상·사업·로드맵 전반에 통합한다.

**원칙:** 백서 생성 시스템을 만들지 않는다. 원고는 직접 편집하고, 설치된 문서·PDF 도구와 일회성 임시 편집 도구만 사용한다. 임시 파일은 작업 뒤 제거한다.

## 작업 1. 원고 구조 개정

**대상:** `docs/whitepaper/MODUA_WHITEPAPER_KO.md`

- 핵심 선언·대표 사용자 여정에 반려 친구와 무모바일 장시간 과업을 추가한다.
- 시장·서비스 장에 사회적 고립, 사람 연결, 반려 Agent의 가치와 증거 한계를 쓴다.
- 모바일을 선택 가능한 개인 통제 접점으로 수정한다.
- 기존 PC 노드 장을 MODUA 제공 보안 실행 노드 중심으로 교체하고 개인 PC는 보조 노드로 이동한다.
- 로봇 장을 추가하고 전체 Node 아키텍처·라우팅·데이터 등급을 연결한다.
- 개인정보 장에 검증가능한 자격증명, 원격 증명, 일회성 권한, 체인·오프체인 경계를 반영한다.
- 보상·사업모델·로드맵·위험·검증 항목을 새 구조와 일치시킨다.

## 작업 2. 근거와 주장 정리

**대상:** `docs/whitepaper/sources.json`, `docs/whitepaper/claims.json`

- 보건복지부 고독사 예방 기본계획을 사회적 연결 정책 배경으로 추가한다.
- 소셜 로봇 연구는 잠재효과와 혼재된 결과를 함께 기록하고 효능 단정을 피한다.
- W3C VC 2.0, IETF RATS, ISO 13482와 공식 온디바이스 로봇 기술자료를 추가한다.
- 모든 신규 외부 주장은 출처 허용 범위 안에 두고, 제품 구조·토큰·보상은 설계결정 또는 조건부 상태로 구분한다.

## 작업 3. 공식 문서 편집

**대상:** `docs/whitepaper/exports/MODUA_WHITEPAPER_KO.docx`, `docs/whitepaper/exports/MODUA_WHITEPAPER_KO.pdf`

- 기존 편집 디자인·한국어 언어 메타데이터·머리말·꼬리말·표 폭을 보존한다.
- 개정 Markdown 전체를 DOCX에 반영하고 PDF를 다시 내보낸다.
- 리포지터리에 빌더·검증기·테스트 파일을 추가하지 않는다.

## 작업 4. 최종 검증

- Markdown·DOCX·PDF의 제목·목록·표·핵심 문구가 일치하는지 확인한다.
- DOCX를 페이지별 이미지로 렌더링해 모든 페이지를 100% 크기로 검사한다.
- PDF를 렌더링해 모든 페이지 또는 DOCX와 픽셀 동등성을 확인한다.
- 접근성, 언어, 표 머리글, 표 폭, 페이지 크기, 링크, 한글 글리프, 잘림·겹침을 검사한다.
- 임시 편집·렌더링 파일을 삭제하고 최종 문서만 커밋한다.
