# IROA.AI Homepage V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready Korean IROA.AI homepage that converts institutional pilot interest and explains the approved whitepaper, safety, ecosystem, and Base Native USDC settlement model.

**Architecture:** A static React 19 and TypeScript site built by Vite. Typed content is separated from presentational components, approved BI assets are imported from `docs/brand`, and semantic CSS tokens control the warm institutional visual system. Vitest covers component behavior and Playwright covers real-browser navigation, responsiveness, and overflow.

**Tech Stack:** React 19.2.8, Vite 8.2.2, TypeScript 7.0.2, Vitest 4.1.11, Testing Library 16.3.2, Playwright 1.62.1, CSS custom properties

**Spec:** `docs/superpowers/specs/2026-08-27-iroa-homepage-v1-design.md`

## Global Constraints

- Primary chain is Base and settlement asset is Circle Native USDC.
- USDC is described only as planned B2B settlement among institutions, merchants, Nodes, and support providers.
- Consumer payment remains KRW, cards, bank transfer, and existing e-wallets; no wallet connection appears on the homepage.
- Health, disability, identity, location, conversation, audio, and video source data are never described as public-chain data.
- Current, planned, pilot, and long-term states are labeled explicitly.
- Use official IROA BI assets without altering proportions or master colors.
- Use IROA Ivory `#F7F3EA`, Navy `#16263D`, Coral `#F06D5E`, Teal `#3D8B83`, and Light Teal `#83CDC4` through semantic CSS variables.
- No text overlays on photography, speculative Web3 imagery, neon, AI purple gradients, auto-playing video, carousel, parallax, or scroll-jacking.
- Interactive targets are at least 44×44px; keyboard focus is visible; reduced motion is respected.
- Verify 375px, 768px, 1024px, and 1440px layouts without horizontal overflow.
- The homepage does not collect inquiry data until an official endpoint or email is configured.
