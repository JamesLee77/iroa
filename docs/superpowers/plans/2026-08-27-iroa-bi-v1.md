# IROA.AI BI v1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 BI 정교화안과 제로베이스안을 동일한 전문 품질 기준으로 완성·비교한 뒤, 선택된 아이덴티티를 운영 가능한 IROA.AI BI v1.0 자산과 가이드로 배포한다.

**Architecture:** 후보 제작과 공식 자산 배포를 분리한다. `docs/brand/candidates`에서 트랙 A/B 마스터를 각각 완성하고 자동 감사와 실사용 렌더를 통과시킨 뒤 단 한 번의 사용자 선택 체크포인트를 둔다. 선택 결과만 `docs/brand/masters`와 `docs/brand/exports`로 승격하고, Python 기반 빌드·감사 도구로 루트 호환 파일, PNG 크기, 대비, DOCX/PDF 가이드의 정합성을 재현 가능하게 검증한다.

**Tech Stack:** SVG, Python 3, `xml.etree.ElementTree`, Pillow, macOS `sips`, `python-docx`, LibreOffice, Poppler, Codex ImageGen/Creative Production review board

**Spec:** `docs/superpowers/specs/2026-08-27-iroa-bi-v1-design.md`

## Global Constraints

- 공식 브랜드명은 `IROA.AI`, 기본 표기 후보는 `iroa.ai`, 한국어 발음은 `이로아`다.
- `iroa.ai` 도메인은 확보 완료이며 상표권 확보와 구분해 표기한다.
- 기존 BI 정교화와 제로베이스 BI를 모두 제작한다.
- 과정 중의 설명용 도형이나 미완성 탐색안은 사용자 비교안으로 제시하지 않는다.
- 제로베이스안은 기존 열린 고리, 행동점, 기존 색상과 기존 워드마크 구조를 출발점으로 사용하지 않는다.
- 뇌, 로봇 얼굴, 말풍선, 하트, 의료 십자, 코인, 육각형 노드 같은 상투적 기호를 사용하지 않는다.
- 두 후보는 흑백, 16/24/32/64px, 역상, 앱 아이콘, 웹, 워치, 키오스크, 문서와 영수증에서 검증한다.
- 최종 핵심 텍스트 조합은 WCAG AA 대비 4.5:1 이상, 큰 텍스트는 3:1 이상이어야 한다.
- 공식 자산은 SVG 마스터, 투명 PNG, 인쇄 PDF, 디지털 아이콘을 포함한다.
- 기존 루트 SVG·PNG 경로는 호환 파일로 유지한다.
- 기존 미추적 협약서와 사용자 변경사항을 수정·추가·삭제·커밋하지 않는다.

```python
# tools/brand/brand_contract.py
from dataclasses import dataclass
from pathlib import Path

OFFICIAL_PNG_SIZES = (16, 24, 32, 48, 64, 128, 180, 192, 256, 512, 1024)


@dataclass(frozen=True)
class CandidatePaths:
    root: Path

    @property
    def symbol(self) -> Path:
        return self.root / "symbol.svg"

    @property
    def wordmark(self) -> Path:
        return self.root / "wordmark.svg"

    @property
    def wordmark_reverse(self) -> Path:
        return self.root / "wordmark-reverse.svg"

    @property
    def wordmark_mono(self) -> Path:
        return self.root / "wordmark-mono.svg"
```

```python
# tools/brand/audit_assets.py
from pathlib import Path
from xml.etree import ElementTree as ET


def _linear(channel: int) -> float:
    value = channel / 255
    return value / 12.92 if value <= 0.04045 else ((value + 0.055) / 1.055) ** 2.4


def _luminance(hex_color: str) -> float:
    raw = hex_color.lstrip("#")
    channels = [int(raw[index:index + 2], 16) for index in (0, 2, 4)]
    red, green, blue = (_linear(channel) for channel in channels)
    return 0.2126 * red + 0.7152 * green + 0.0722 * blue


def contrast_ratio(foreground: str, background: str) -> float:
    lighter, darker = sorted((_luminance(foreground), _luminance(background)), reverse=True)
    return (lighter + 0.05) / (darker + 0.05)


def audit_svg(path: Path) -> None:
    root = ET.parse(path).getroot()
    names = {element.tag.rsplit("}", 1)[-1] for element in root}
    if not {"title", "desc"}.issubset(names):
        raise ValueError(f"{path} must include title and desc")
    if not root.attrib.get("viewBox"):
        raise ValueError(f"{path} must include viewBox")
    if root.findall(".//{http://www.w3.org/2000/svg}image"):
        raise ValueError(f"{path} must not embed raster images")
```
