# IROA.AI BI v1.0 설계

날짜: 2026-08-27  
상태: 승인된 설계  
대상: `docs/brand` 브랜드 자산과 BI 가이드

## 1. 목적

IROA.AI의 기존 BI를 정식 운영 가능한 v1.0 브랜드 시스템으로 완성하고, 기존 조형에 의존하지 않는 제로베이스 아이덴티티를 동일한 품질 기준으로 제작해 비교한다. 과정 중의 설명용 도형이나 미완성 탐색안은 검토안으로 제시하지 않는다. 형태, 비례, 간격, 소형 식별성과 실제 적용 품질을 통과한 최종 후보만 비교한다.

최종 BI는 IROA의 핵심 약속인 “일상을 이롭게. 필요한 일을 끝까지.”를 담되, 로고가 장문의 설명에 의존하지 않고 독립적인 시각 자산으로 성립해야 한다.

## 2. 고정된 브랜드 조건

- 공식 브랜드명: `IROA.AI`
- 기본 표기 후보: `iroa.ai`
- 한국어 발음: 이로아
- 브랜드 역할: 노인과 장애인의 생활 요청을 실제 결과와 사람 도움까지 연결하는 AI 지원망
- 브랜드 성격: 따뜻함, 신뢰, 사용자 주도성, 포용성, 실행력
- 금지 인상: 유아적 돌봄 캐릭터, 차가운 의료기관, 감시 기술, 과장된 미래주의, 암호화폐·코인 프로젝트
- 법적 사실: `iroa.ai` 도메인은 확보 완료. 도메인 확보와 상표권 확보는 구분한다.

## 3. 제작 방식

### 3.1 트랙 A — 기존 BI 정교화

현재 `iroa.ai` 워드마크, 열린 고리 심볼, 행동점을 정체성의 기반으로 유지한다. 다만 기존 벡터를 그대로 확정하지 않고 다음 항목을 다시 설계한다.

- 글자별 획 굵기와 곡률의 일관성
- `i`, `r`, `o`, `a`, `.ai`의 시각적 무게와 기준선
- 행동점의 개수, 크기, 위치와 의미 중복
- 워드마크와 심볼의 형태적 친연성
- 가로형, 축약형, 심볼형의 비례와 보호 공간
- 16px부터 인쇄 대형까지의 광학 보정
- 컬러, 역상, 단색에서의 동일한 식별성

목표는 기존 인상을 유지하는 미세 수정이 아니라, 기존 아이디어를 전문적인 마스터 아트워크로 다시 완성하는 것이다.

### 3.2 트랙 B — 제로베이스 BI

기존 열린 고리, 행동점, 네이비·코랄·청록과 기존 워드마크 구조를 출발점으로 사용하지 않는다. 흑백 조형과 워드마크 구조부터 시작해 IROA만의 식별성을 새로 만든다.

- 최초 평가는 흑백으로 진행한다.
- 심볼만 만든 뒤 임의 서체를 붙이지 않고, 워드마크와 심볼을 하나의 조형 체계로 개발한다.
- 사람, 접근성, 요청, 연결, 완료 같은 단어를 단순 아이콘으로 치환하지 않는다.
- 뇌, 로봇 얼굴, 대화 말풍선, 하트, 의료 십자, 코인, 육각형 노드 같은 상투적 기호를 배제한다.
- 제로베이스안은 기존안과 다른 형태 언어를 가져야 하며, 설명이 아니라 실루엣과 문자 조형으로 경쟁한다.

내부 탐색은 넓게 수행하되 사용자에게는 전체 품질 기준을 통과한 단일 제로베이스 최종안만 제시한다.

## 4. 공통 시각 품질 기준

두 트랙은 동일한 기준으로 평가한다.

1. **고유성**: 일반적인 AI·복지·의료·블록체인 로고와 즉시 구분된다.
2. **문자 완성도**: 획, 곡률, 카운터, 자간, 기준선과 광학 중심이 안정적이다.
3. **소형 식별성**: 16px 파비콘, 24px 워치, 32px 앱 목록에서 무너지지 않는다.
4. **단색 성립성**: 색을 제거해도 브랜드가 유지된다.
5. **접근성**: 핵심 조합은 WCAG 대비 기준을 충족하고 색만으로 의미를 전달하지 않는다.
6. **확장성**: 모바일, 워치, 키오스크, 웹, 문서, 인쇄와 NODE 인증 표시에 일관되게 적용된다.
7. **존중감**: 노인과 장애인을 수동적 보호 대상이나 환자로 표현하지 않는다.
8. **기억성**: 짧게 본 뒤 실루엣이나 문자 특징을 다시 떠올릴 수 있다.
9. **국제성**: 한국어 발음과 영문 표기가 모두 자연스럽고 특정 국가·기관 브랜드로 오인되지 않는다.
10. **장기성**: 유행하는 AI 그래픽 효과 없이도 장기간 사용할 수 있다.

하나라도 중대한 결함이 있으면 최종 비교안으로 올리지 않는다.

## 5. 비교 방식과 선택

최종 비교는 트랙 A와 트랙 B 두 안만 동일 조건으로 제시한다.

- 흑백 마스터
- 기본 컬러와 역상
- 심볼 단독 16/24/32/64px
- 가로형 워드마크
- 앱 아이콘과 파비콘
- 웹 헤더
- 워치 알림
- 키오스크 시작 화면
- 백서·공식 문서 표지
- 단색 인쇄와 작은 영수증

설명문은 조형의 결함을 보완하는 수단으로 사용하지 않는다. 먼저 시각 결과를 비교하고, 이후에 브랜드 의미와 운영상 장단점을 설명한다. 선택되지 않은 안은 연구 기록으로만 보존하고 공식 BI에 혼합하지 않는다.

## 6. 최종 자산 범위

선택된 BI는 다음 마스터와 배포 자산을 갖는다.

### 6.1 로고

- 기본 가로형 워드마크
- 축약형 락업
- 심볼
- 밝은 배경용, 어두운 배경용, 단색형
- SVG 마스터
- 투명 배경 PNG 16, 24, 32, 48, 64, 128, 256, 512, 1024px
- 인쇄용 PDF

### 6.2 디지털 아이콘

- favicon SVG 및 16/32/48px PNG
- Apple touch icon 180px
- Android/웹 앱 아이콘 192/512px
- 마스크 가능 아이콘용 안전 영역 버전
- 워치와 키오스크 상태표시용 소형 심볼

### 6.3 디자인 토큰

- 기본·보조·중립·상태 컬러와 HEX/RGB/CMYK
- 허용되는 텍스트·배경 조합과 대비값
- 한국어·영문 서체와 대체 서체
- 제목·본문·캡션의 기본 크기와 행간
- 모서리, 선, 간격과 사진 처리 원칙

### 6.4 운영 가이드

- 로고 구조와 보호 공간
- 최소 크기와 광학 보정 버전
- 배경별 사용 규칙
- 공동 브랜딩과 파트너 로고 배치
- 제품명과 서브브랜드 표기
- 접근성 및 금지 사용
- 문서, 웹, 앱, 워치, 키오스크 적용 예시
- 자산 파일 목록과 사용 목적

## 7. 파일 구조

`docs/brand`는 다음 구조로 정리한다.

```text
docs/brand/
├── IROA_BI_GUIDE_KO.md
├── IROA_BI_GUIDE_KO.docx
├── IROA_BI_GUIDE_KO.pdf
├── README.md
├── masters/
│   ├── symbol/
│   ├── wordmark/
│   └── lockup/
├── exports/
│   ├── digital/
│   ├── print/
│   └── icons/
├── examples/
└── assets/photos/
```

기존 경로를 사용하는 소비자가 있을 수 있으므로 현재 루트의 대표 SVG·PNG 파일은 호환 경로로 유지하거나 명시적으로 이전한다. 파일명은 소문자 영문, 용도, 배경, 색상과 크기가 드러나도록 통일한다.

## 8. 검증

- SVG 문법과 `viewBox` 검증
- 모든 PNG의 실제 크기, 알파 채널과 색상 확인
- 밝은 배경·어두운 배경의 WCAG 대비 계산
- 16/24/32px 실제 래스터 출력 육안 검사
- A4 문서, 1280px 웹 헤더, 앱 아이콘, 워치, 키오스크 적용 렌더링
- DOCX와 PDF BI 가이드 전체 페이지 렌더링 검사
- 기존 백서와 가이드에서 깨진 로고·사진 링크 검사
- 공식 자산 외 중복·구형 파일을 README에서 명확히 구분
- 원본과 배포본의 버전·날짜·도메인 상태 일치 확인

## 9. 완료 조건

다음 조건이 모두 충족되면 BI v1.0을 완료로 판단한다.

- 두 트랙의 최종안이 공통 품질 기준을 통과했다.
- 한 개의 공식 BI가 선택됐다.
- 로고 마스터와 모든 필수 배포 크기가 생성됐다.
- BI 가이드 Markdown, DOCX, PDF가 동일한 내용을 가진다.
- 소형·단색·역상·접근성·실사용 렌더 검증이 통과했다.
- `iroa.ai` 도메인 확보와 상표권 미확정 상태가 정확히 구분됐다.
- 기존 미추적 문서와 사용자 변경사항은 손상되지 않았다.
