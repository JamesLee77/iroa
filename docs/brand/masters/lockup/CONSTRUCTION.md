# IROA official horizontal lockup construction

The official horizontal lockup places the unmodified selected Track A symbol in a `160 x 160` unit frame, vertically centered in the wordmark's `600 x 180` unit frame. The wordmark begins at `x = 160`; because the selected symbol's visible geometry ends at `x = 140` and the wordmark's visible geometry begins at `x = 37.5`, this yields at least `57.5` units of visible separation. That exceeds the required 24-unit symbol-stroke clear space without introducing a new logo shape or changing either selected master geometry.

Color, monochrome, and reverse versions retain the same placement. The reverse lockup uses one navy context field behind the unchanged reverse artwork so it works as a single lockup rather than adjacent panels.
