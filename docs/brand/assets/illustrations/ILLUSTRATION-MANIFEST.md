# IROA Whitepaper Illustration Manifest

## Production system

- Direction: Unified Network Atlas
- Medium: premium editorial 3D illustration
- Canvas: 1672 × 941 PNG
- Palette: Ivory `#F7F3EA`, Navy `#16263D`, Coral `#F06D5E`, Teal `#3D8B83`
- Shared rule: Coral represents a request or approval path; Teal represents a verified result, handoff, or settlement path.
- Exact content rule: labels, claims, token values, logos, and legal language remain in Markdown, HTML, DOCX, and deterministic charts. They are not baked into generated illustrations.
- Generator: built-in Codex ImageGen
- Generated: 2026-08-28
